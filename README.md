# Chat App

Welcome to the Chat App! This application enables real-time communication between users, providing a seamless and interactive chatting experience.

## Features

- **Real-Time Messaging**: Engage in instant conversations with other users.
- **User Authentication**: Secure login and registration system to protect user data.
- **Chat Rooms**: Join existing chat rooms or create new ones to connect with multiple users.
- **Typing Indicators**: See when another user is typing a message.
- **Message Notifications**: Receive alerts for new messages even when you're not active in the chat.

## Technologies Used

- **Frontend**: React.js for building dynamic user interfaces.
- **Backend**: Node.js and Express.js to handle server-side logic and API requests.
- **Database**: MongoDB for storing user information and chat histories.
- **Real-Time Communication**: Socket.IO to facilitate instant messaging between users.
